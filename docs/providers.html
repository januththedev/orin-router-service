Providers

A provider is one of your API keys plus the knowledge of which models it serves. Supported types: OpenRouter, Groq, and custom (any OpenAI-compatible base URL — guarded against private/internal hosts).

Model lists & wildcards

List the models a provider serves (comma separated). A provider with an empty list is a wildcard: it accepts any model string and sits behind exact matches in priority. Exact matches always win over wildcards.

Managing providers

  • Test runs one real request through the provider and reports latency.
  • Disable takes a provider out of rotation without deleting it (re-enabling needs no key re-entry).
  • Delete removes the provider and its stored key permanently.
  • Keys are AES-GCM encrypted in the database and never returned by any endpoint.
