Authentication

Orin Router has two credentials for two jobs. They are deliberately separate: a leaked gateway key can never open your dashboard.

Orin login → dashboard

Sign in with your Orin account (same email and password as Orin Chat) or a scoped MCP credential. This unlocks providers, keys, usage and logs — all strictly scoped to your account. Other users' data is invisible.

Gateway keys → API

  • Mint keys in the dashboard: name + optional per-minute limit. The secret (orin_…) is shown exactly once — copy it immediately.
  • Only SHA-256 hashes are stored; secrets can't be recovered or re-shown.
  • One key serves one user's providers. Revoking a key breaks apps using it instantly — provider keys are untouched.
  • Use it as a Bearer token: Authorization: Bearer orin_…
