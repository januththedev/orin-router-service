Introduction

Orin Router turns many provider keys into one API. Add your OpenRouter, Groq and OpenAI-compatible keys in the dashboard, mint a single gateway key, and point any OpenAI client at router.orinai.org/v1.

The request path

  1. You request a model, e.g. x-ai/grok-4-1-fast.
  2. The router finds your enabled providers serving it — exact match first, wildcard providers after, in the order you added them.
  3. Providers are tried top-down. The first success wins; failures fall over to the next provider automatically. See Routing.

What the router never does

  • Never shows provider keys again after you save them.
  • Never logs secrets — only key prefixes and metadata.
  • Never stores prompt or completion text — only character counts.
