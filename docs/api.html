API reference

Every endpoint requires an Orin Core service assertion with audience orin-router and scope router:invoke. Browser dashboard tokens and MCP credentials are not accepted.

GET /v1/models

Returns exactly orin-cheap, orin-balanced, orin-thinking, and orin-coding.

POST /v1/chat/completions

{
  "model": "orin-balanced",
  "messages": [{ "role": "user", "content": "Hello" }],
  "stream": false
}

Streaming responses authenticate and validate before headers commit. Provider failover is allowed only before the first semantic event. A committed stream ends with one typed terminal event and one data: [DONE].

POST /v1/images/generations

{
  "model": "orin-balanced",
  "prompt": "A quiet lake at sunrise",
  "n": 1,
  "response_format": "b64_json"
}

Errors

{ "error": { "code": "ORIN_PROVIDER_EXHAUSTED", "message": "No eligible provider is currently available.", "retryable": true, "retry_after": null, "request_id": "..." } }

Internal routes

Catalog refresh and attempt reconciliation are private, authenticated service routes. They are not public client APIs.
