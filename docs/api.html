API reference

Base URL https://router.orinai.org/v1. Authenticate with a gateway key: Authorization: Bearer orin_… All errors are OpenAI-shaped {error: {message, type, code}}.

GET /v1/models

Lists your configured models (the union of your providers' model lists). Requires a gateway key — each caller sees only their own models.

POST /v1/chat/completions

{
  "model": "x-ai/grok-4-1-fast",
  "messages": [{ "role": "user", "content": "Hello" }],
  "temperature": 0.7,
  "max_tokens": 512,
  "stream": false
}

With "stream": true the endpoint returns SSE data: deltas plus data: [DONE]. Unknown models return 400 listing what's available.

Rate limits & status codes

  • 401 missing/invalid key · 403 disabled key · 429 per-key per-minute limit exceeded.
  • 400 bad body or unknown model · 502/504 all providers failed (last error surfaced).
  • Every request is logged with request ID, provider, latency and status — inspect it in Logs.
